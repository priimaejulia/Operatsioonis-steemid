| Ülesanne 10 - 15 ( Aeglane arvuti)              |                                                                                                                                                                                                                                                               | 1. Tegumihaldur -> Protsessid: sorteerin välja veerud Protsessor, Mälu ja Ketas. Kahtlane on see protsess, mis kasutab püsivalt üle 80% CPU-d või kui Ketas on pidevalt 100%.<br>2. Tegumihaldur -> Jõudlus -> Mälu: kui mälu on üle 90% täis, siis ei mahu programmid enam mällu. Windows hakkab mälu asemel kasutama kõvaketast, mis on palju aeglasem, ning arvuti muutub sellega aeglasemaks.<br>3. Resource Monitor -> Disk: Resource Monitor'is vaatan vahelehte Disk. Kui Active Time on peaaegu 100% ja Disk Queue Lenght on pidevalt üle 2, siis ketas ei jõua tööga järele ja see teeb arvuti aeglaseks. Veergudes Read ja Write (B/sec) näen, milline programm ketast kõige rohkem kasutab.<br>4. Resource Monitor -> Network: jaotises Processes with Network Actitvity vaatan, kas mõni protsess kasutab ootamatult palju võrku ( näiteks taustal toimub allalaadimine).<br>5. Tegumihaldur -> Käivitusrakendused: Tegumihalduris vaatan vahelehte Käivitusrakendused, kuna seal on programmid, mis käivituvad arvuti sisselülitamisel ise. Veerust Käivitusmõju vaatan, kui palju iga programm käivitamist aeglustab. Kui mõju on "Suur" ja programmi pole vaja, siis lülitan selle välja. <br>6. Autoruns: vahelehel Everything vaatan veergu Publisher. Kui see on tühi või tundmatu ning rida on punase taustaga, siis võib see olla pahavara.<br>7. See arvuti -> C: : kui põhikettal on vaba ruumi alla 10 - 15%, siis see aeglustab süsteemi.  |                                                                                                                                              |                                                                                                                                                                                                                               |
